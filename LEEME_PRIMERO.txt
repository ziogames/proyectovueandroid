┏──────────────────────────────────────────────────────────────────────────────┓
┃ 📊 RESUMEN TÉCNICO                                                          ┃
┗──────────────────────────────────────────────────────────────────────────────┛

ENDPOINT API:
  POST /api/images/compare/
  Parámetros: uploaded_image (archivo), threshold (0-1)
  Retorna: JSON con resultados ordenados por similitud

ALGORITMOS:
  • ORB (60%): Detecta características visuales
  • Histogramas (40%): Analiza color RGB
  • Combinado: Similitud final 0-1

RENDIMIENTO:
  • 10 llaves: 0.5-1 segundo
  • 50 llaves: 2-3 segundos
  • 100 llaves: 4-6 segundos

INTERFAZ:
  • Responsive (desktop, tablet, móvil)
  • Drag-and-drop de imágenes
  • Visualización de resultados
  • Detalles expandibles

┃ 🎯 CÓMO USAR                                                                ┃
┗──────────────────────────────────────────────────────────────────────────────┛

EN LA APLICACIÓN:
  1. Ve a: Menú Izquierdo → COMPARADOR DE IMÁGENES
  2. Carga: Arrastra imagen o haz clic
  3. Ajusta: Similitud (deslizador, opcional)
  4. Compara: Haz clic "Comparar Imágenes"
  5. Revisa: Resultados ordenados por similitud

DESDE CÓDIGO PYTHON:
  from api.image_comparison import compare_with_database
  
  results = compare_with_database(
      image_bytes, database_images, threshold=0.6
  )

DESDE API REST:
  curl -X POST http://localhost:8000/api/images/compare/ \
    -H "Authorization: Bearer {TOKEN}" \
    -F "uploaded_image=@imagen.jpg" \
    -F "threshold=0.6"

┏──────────────────────────────────────────────────────────────────────────────┓
┃ 💡 TIPS Y TRUCOS                                                            ┃
┗──────────────────────────────────────────────────────────────────────────────┛

PARA MEJORES RESULTADOS:
  ✓ Usa imágenes claras y bien iluminadas
  ✓ Captura toda la llave en frame
  ✓ Usa fondo simple o uniforme
  ✓ Evita sombras y reflejos fuertes

SI NO FUNCIONA:
  ✓ Verifica que tengas imágenes en la BD
  ✓ Prueba con umbral más bajo (40% vs 60%)
  ✓ Intenta con imagen de mejor calidad
  ✓ Mira los logs en la consola (F12)

PARA OPTIMIZAR:
  ✓ Usa imágenes de menor resolución
  ✓ Comprime imágenes PNG
  ✓ Procesa en lotes (ver EJEMPLOS_COMPARADOR.py)


┏──────────────────────────────────────────────────────────────────────────────┓
┃ 🐛 TROUBLESHOOTING RÁPIDO                                                   ┃
┗──────────────────────────────────────────────────────────────────────────────┛

PROBLEMA: "cv2 module not found"
SOLUCIÓN: pip install --upgrade opencv-python

PROBLEMA: "No hay imágenes disponibles"
SOLUCIÓN: Carga imágenes en "Inventario de Llaves"

PROBLEMA: "413 Payload Too Large"
SOLUCIÓN: Aumenta limites en backend/settings.py

PROBLEMA: "Resultados inesperados"
SOLUCIÓN: Prueba con umbral más bajo, usa mejor imagen

Para más ayuda ver: INSTALACION_COMPARADOR.md → Troubleshooting
