1. INTRODUCCIÓN
───────────────────────────────────────────────────────────────────────────────

Se ha implementado exitosamente una funcionalidad completa de "Comparador de
Imágenes" que permite a los usuarios:

✓ Cargar una imagen de una llave
✓ Compararla automáticamente con todas las llaves en la base de datos
✓ Obtener resultados ordenados por similitud
✓ Identificar la llave exacta que buscan

Esta implementación utiliza técnicas avanzadas de visión por computadora
(OpenCV, ORB y análisis de histogramas) para obtener resultados precisos
y confiables.

5. ARQUITECTURA TÉCNICA
───────────────────────────────────────────────────────────────────────────────

FLUJO DE DATOS:

  Usuario (Frontend)
       ↓
  Vue.js: ImageComparison.vue
  - Valida tipo y tamaño
  - Crea preview
  - Prepara FormData
       ↓
  HTTP POST /api/images/compare/
       ↓
  Django Backend
  - ImageComparisonView
  - Valida archivo
  - Obtiene llaves de BD
       ↓
  Python: image_comparison.py
  - ImageComparator.compare_images()
  - Método 1: ORB (60%)
    • Detecta características
    • Empareja puntos
    • Calcula similitud
  - Método 2: Histogramas (40%)
    • Analiza color RGB
    • Calcula Bhattacharyya
  - Combina: 0.6*ORB + 0.4*Hist
       ↓
  JSON Response
  - results[]
  - total
  - matches
       ↓
  Vue.js: Muestra resultados
  - Gráficos de similitud
  - Tabla de resultados
  - Detalles expandibles


ALGORITMOS:

1. ORB (Oriented FAST and Rotated BRIEF):
   - Detecta esquinas rápidamente (FAST)
   - Extrae descriptores binarios (BRIEF)
   - Empareja puntos entre imágenes
   - Calcula distancia promedio normalizada
   - Resultado: Similitud 0-1

2. Histogramas de Color:
   - Analiza distribución RGB
   - Métrica Bhattacharyya Distance
   - Compara espectrales de color
   - Robusto a iluminación
   - Resultado: Similitud 0-1

3. Combinación:
   - Similitud Final = (ORB × 0.6) + (Histograma × 0.4)
   - Pesos ajustables en configuración
   - Resultado final: 0-1 (0%-100%)

10. INSTRUCCIONES DE USO
───────────────────────────────────────────────────────────────────────────────

PASO 1: INICIAR SERVIDOR BACKEND
  $ python manage.py runserver
  → Corre en http://localhost:8000

PASO 2: INICIAR SERVIDOR FRONTEND
  $ cd frontend
  $ npm run dev
  → Corre en http://localhost:5173

PASO 3: ACCEDER A LA APLICACIÓN
  → Abre http://localhost:5173 en el navegador
  → Inicia sesión con tus credenciales

PASO 4: USAR COMPARADOR
  → En el menú izquierdo: COMPARADOR DE IMÁGENES
  → Arrastra imagen o haz clic
  → Ajusta similitud (opcional)
  → Haz clic "Comparar Imágenes"
  → Revisa resultados

ENDPOINT API:
  POST /api/images/compare/
  Headers:
    Authorization: Bearer {JWT_TOKEN}
    Content-Type: multipart/form-data
  Parámetros:
    - uploaded_image: archivo de imagen
    - threshold: similitud mínima (0.0-1.0)

12. CASOS DE USO
───────────────────────────────────────────────────────────────────────────────

1. IDENTIFICACIÓN DE LLAVE DESCONOCIDA
   Problema: Encontré una llave sin etiqueta
   Solución: Toma foto → Carga en comparador → Identifica automáticamente
   Beneficio: Evita buscar manualmente

2. VERIFICACIÓN DE DUPLICADOS
   Problema: ¿Tengo dos llaves iguales?
   Solución: Fotografía ambas → Compara → Obtiene resultado
   Beneficio: Organizar inventario correctamente

3. CONTROL DE CALIDAD
   Problema: Verificar recibos vs. imágenes en BD
   Solución: Fotografía recibo → Compara → Valida
   Beneficio: Garantizar exactitud de pedidos

4. BÚSQUEDA RÁPIDA
   Problema: Buscar llave por código es lento
   Solución: Fotografía → Sistema la identifica
   Beneficio: 10x más rápido que búsqueda manual

5. AUTOMATIZACIÓN
   Problema: Procesar cientos de imágenes manualmente
   Solución: Script Python con lote
   Beneficio: Procesamiento masivo automático
