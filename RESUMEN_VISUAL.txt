┌─────────────────────────────────────────────────────────────────────────────┐
│ 🎯 CASOS DE USO                                                            │
└─────────────────────────────────────────────────────────────────────────────┘

  1. 🔑 IDENTIFICAR LLAVE DESCONOCIDA
     Encontraste una llave sin etiqueta
     → Toma foto → El sistema la identifica

  2. 🔍 VERIFICAR DUPLICADOS
     ¿Tengo dos llaves iguales?
     → Compara ambas imágenes → Obtén resultado

  3. ✅ CONTROL DE CALIDAD
     Verificar recibos vs. fotos
     → Carga imagen de recibo → Verifica con BD

  4. 📊 BÚSQUEDA RÁPIDA
     Buscar llave por imagen en lugar de código
     → Fotografía → Instantáneo resultado

  5. 🏭 AUTOMATIZACIÓN
     Procesar lotes de imágenes
     → Script Python → Resultados en CSV

┌─────────────────────────────────────────────────────────────────────────────┐
│ 🐛 TROUBLESHOOTING                                                         │
└─────────────────────────────────────────────────────────────────────────────┘

  ❌ "cv2 module not found"
     ✅ pip install --upgrade opencv-python

  ❌ "No hay imágenes disponibles"
     ✅ Carga imágenes en Inventario de Llaves

  ❌ "413 Payload Too Large"
     ✅ Aumenta límites en backend/settings.py

  ❌ "Resultados inesperados"
     ✅ Prueba con umbral más bajo
     ✅ Usa imágenes de mejor calidad

  ❌ "CORS Error"
     ✅ Verifica CORS_ALLOWED_ORIGINS en settings.py
