## 🎯 Cómo Usar Paso a Paso

### 1️⃣ Abre el Comparador de Imágenes
   - Ve a la aplicación
   - Busca la sección "Comparador de Imágenes"

### 2️⃣ Carga una Imagen de una Llave
   **Tienes 3 opciones:**
   
   📷 **En Móvil:**
   - Toca el botón "Cámara" para tomar foto
   - O toca "Galería" para seleccionar de tu móvil
   
   🖥️ **En Computadora:**
   - Haz clic en "Buscar en mi PC"
   - O arrastra la imagen directamente

### 3️⃣ (Opcional) Ajusta la Similitud
   ```
   Umbral: ████████░░ 60%
           ← Baja (más resultados) | Alta (solo exactas) →
   ```
   - Más bajo: Encontrará más llaves parecidas (pero menos exactas)
   - Más alto: Solo encontrará llaves muy similares

### 4️⃣ Haz Clic en "Comparar Imágenes"
   - Sistema buscará coincidencias
   - Espera a que termine (unos segundos)

### 5️⃣ Explora los Resultados
   
   **En Computadora:**
   - Verás una grilla de 3 columnas
   - Cada cuadro tiene la imagen de la llave
   
   **En Móvil:**
   - Verás miniaturas horizontales
   - Desliza para ver más

### 6️⃣ Selecciona una Coincidencia
   - Haz clic en cualquier llave
   - Se abre un panel con detalles completos

## 🎨 Entendiendo los Colores

### Barras de Similitud:
- 🟢 **Verde (80-100%)**  → ¡Muy probable! Es la llave que buscas
- 🟡 **Amarillo (60-79%)** → Probable. Muy parecida
- 🟠 **Naranja (40-59%)**  → Moderada. Se parece algo
- 🔴 **Rojo (< 40%)**      → Baja. No es muy parecida

### Tipos de Análisis:
- 📊 **General**: Combinación de todos los análisis
- 🔍 **Características**: Detalles de forma/estructura
- 📏 **Líneas**: Bordes y contornos
- 🎨 **Color**: Tonos y colores

## 💡 Consejos de Uso

### Para mejores resultados:

1. 📸 **Toma fotos claras**
   - Buena iluminación
   - Llave enfocada
   - Fondo neutral

2. 🎯 **Prueba diferentes ángulos**
   - De frente
   - Lateral
   - Ambos lados

3. 📊 **Ajusta el umbral según necesites**
   - Bajo (40-50%): Para búsquedas amplias
   - Medio (60-70%): Más específico
   - Alto (80%+): Solo exactas

4. 🔄 **Si no encuentras nada:**
   - Baja el umbral
   - Intenta otra foto
   - Verifica que las imágenes estén en la base de datos

## 🆘 Preguntas Frecuentes

**P: ¿Por qué no me muestra imágenes?**
> Las imágenes deben estar subidas en la base de datos para la llave. Si no ves imagen, es porque la llave no tiene una foto asociada.

**P: ¿Cuántas coincidencias puede encontrar?**
> Puede encontrar todas las llaves en la base de datos. Cuanto más baje el umbral, más resultados mostrará.

**P: ¿Qué formatos de imagen acepta?**
> JPG, PNG, BMP y TIFF. Máximo 10MB.

**P: ¿Funciona sin internet?**
> No, es una aplicación web y necesita conexión al servidor.

**P: ¿Se guardan mis fotos?**
> No. Solo se usan para hacer la búsqueda. Se descartan inmediatamente.
