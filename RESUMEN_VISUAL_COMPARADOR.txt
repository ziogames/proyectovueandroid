## Flujo de Uso

### Paso 1: Cargar Imagen
```
[Tu Llave] ← Sube imagen o usa cámara
```

### Paso 2: Ajustar Umbral
```
Umbral: ████████░░ 60%
(Más bajo = más resultados)
```

### Paso 3: Buscar
```
Botón: "Comparar Imágenes" → Procesando...
```

### Paso 4: Explorar Resultados
```
Desktop:     Haz scroll ↓ o ve la grilla
Móvil:       Desliza ← → en el carrusel
```

### Paso 5: Ver Detalles
```
Haz clic en cualquier coincidencia
↓
Se expande con:
  • Imágenes lado a lado
  • Información completa
  • Análisis detallado
```

## Indicadores Visuales

### Códigos de Color
```
VERDE   ███████░░░ 80-100% → Coincidencia muy probable
AMARILLO ██████░░░░ 60-79%  → Coincidencia probable
NARANJA ████░░░░░░░ 40-59%  → Similitud moderada
ROJO    ██░░░░░░░░░ < 40%   → Baja similitud
```

### Elementos Interactivos
```
[Tarjeta] → Hover: brillo y sombra
          → Clic: Expande detalles

[Imagen] → Hover: Zoom 105%
        → Clic: Selecciona coincidencia

[Miniatura] → En carrusel móvil
            → Clic: Abre detalles
            → Borde verde: seleccionada
```
